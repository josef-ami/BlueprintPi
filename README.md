# BluePrint Pi
## All that lives in the Pi5 of Team Blueprint's bot for WRO 2026 APAC

### Setup Procedure
1.  `sudo apt install -y python3-libcamera python3-kms++ python3-picamera2`
2.  `python3 -m venv --system-site-packages env`
3.  `source env/bin/activate`
4.  `pip install -r requirements.txt`
